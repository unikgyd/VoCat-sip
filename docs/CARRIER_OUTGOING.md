# 可选分机 → 模组 IMS 外呼

分机 B2BUA 现在可以通过逐模组适配器外呼，并将 PCMA／PCMU RTP 与 IMS 的
8 kHz 单声道 PCM 直接双向桥接。不经过浏览器或主机音频设备。

当前按每台设备保存的模式接入**已经注册的 VoWiFi 或 Host IMS**，应用与模式 UI
接线见 [Host IMS 应用接入](HOST_IMS_APPLICATION.md)；没有新增 Linux USB 双向音频后端。
不主动注册、切换模式／SIM、不用 ATD 回退，也不在指定线路失败时换卡重拨。
真实运营商／软电话验收尚未进行，合成测试不代表运营商开通或资费保证。
原 LICENSE、地域、设备和其他现有授权检查保持不变。

## 配置与使用

SIP 服务、通话权限和模组外呼均默认关闭，外线、账号与号码规则不预置：

1. 在模组页选择并启用 VoWiFi 或 Host IMS，按该模式前提完成注册，确认当前 SIM 已验证、
   IMS 已就绪；选择 Host IMS 不代表已自动完成射频准备或接管基带 IMS。
2. 在「设置 → SIP 分机服务」配置自己的账号、监听地址、身份域和可信网段，
   开启分机服务与分机通话。软电话使用 PCMA 或 PCMU。
3. 在「模组通话桥接」添加配置过的模组，显式开启该线路的外呼权限。
   可设一条默认线，或仅使用指定选线前缀；前缀可自由配置，不固定为某个数字。
4. 国家码与国内号码位数可选。只有长度精确匹配时才加 `+国家码`；不配置时要求
   `+` 开头的完整国际号码。号码最终须为 7–15 位数字，不能借此拨短码或 USSD。
5. 在每个分机的「允许外呼线路」中逐条授权；默认线不会自动授权所有分机。
   保存后生效，重启恢复已保存的开关。保存／恢复本身不会拨号。

外呼可能收费。活动通话期间更改配置会被拒绝，须先挂断；显式关闭 SIP 服务会
结束它拥有的通话，但不注销整个模组 IMS，也不改模组配置。

## 选线与隔离

- 先查已配置分机号，之后才查外线；分机离线／拒绝通话也不会变成手机外呼。
- 指定前缀按最长匹配选线，再去掉前缀、做该线的号码规范化；无前缀才用默认线。
- 精确选中的线还需通过全局开关、线路开关、分机通话和该分机逐线权限。
  无默认线、号码不完整、线路不可用或未授权时明确失败，不尝试其他 SIM。
- 每条模组线路独立占用；同线第二通忙线，不影响另一模组的同时通话。
  现有 IMS 会话准入也检查网页／本地发起的通话及待决取消，见
  [IMS 生命周期](IMS_CALL_LIFECYCLE.md)。
- 适配器再次检查当前已注册 IMS、实体模组和 SIM 一致性，沿用现有地域限制。
  退出、失卡或策略变化后的已知 Call-ID 清理不走新的外呼／AT 路径。

## 收费操作防重与媒体

向 IMS 提交前，必须成功保存私有操作记录 `sip.gateway.call-operations.private.v1`。
以 Realm、认证分机和原始 SIP Call-ID 的哈希识别操作，不依赖易变的源地址、
Via 分支或 CSeq；相同调用在监听器重启后也不自动重拨。变更目标的重复请求拒绝。
记录只存哈希与到期时间，不存明文号码、SIM 身份、账号或 SIP 正文。

结果不确定的尝试保留 24 小时，最多 2048 条；数据库不可用、损坏或满额时，
在提交运营商前失败。需要重试时由用户明确发起新通话；这不是跨多进程的收费
去重服务，也不能替代软电话自己的操作确认。一个部署只运行一个网关管理器。

双向媒体复用 IMS 的 G.711 编解码实现。上行队列最多约 320 ms，丢弃积压旧帧，
不把语音排成长延迟；同 SSRC 的重复／旧 RTP 不重复注入。下行生成独立序号、
SSRC 和 8 kHz 时间戳，按 20 ms 输出。每条 SIP 媒体腿仍固定到信令来源 IP，
首次合法 RTP 学习端口。挂机关闭自己的 SIP RTP，后台有界结束对应 IMS Call-ID。

IMS 后端可提供 PCMA／PCMU 或 AMR-NB 的 PCM；实际 AMR 编解码仍依赖
[可选原生后端](AMR_MEDIA.md)，默认静态构建未启用，不能把 AMR 标签或注册绿灯
当作可用语音。后续已补 [RFC 4733 DTMF 跨腿](SIP_DTMF.md)及显式 [USB 模组媒体](MODULE_VOICE.md)。
该初始阶段未新增 AMR-WB、RTCP、SIP INFO DTMF、保持、转接、TLS、SRTP 或公网 SBC。
后续 RTCP、SIP INFO 和 IMS 保持的实现／验收分别见 [RTCP](RTCP.md)、
[DTMF](SIP_DTMF.md)和[保持边界](IMS_CALL_HOLD.md)。

## 状态与验证边界

后续 [2026-10-27 纯 Host IMS 联合实测](VERIFICATION_20261027_HOSTIMS_SIP.md)已完成
真实 Baresip PCMU 分机到电信 AMR 通话：接听者确认听到提示音并说话，双向媒体、RTCP
和手机 5／8 按键到达分机均有证据。该限定场景不替代远端 IVR 识别、跨网段或其他模式验收。
以下回环与合成检查保留为此前阶段的证据。

设置 API 仍为认证、CSRF 保护的 `/api/settings/sip`。新增 `carrier_enabled`、
`carrier_lines` 和分机 `outgoing_lines`；快照深拷贝嵌套权限。
`carrier_outgoing` 表示该能力已实现且启用，不表示目标 SIM 已注册；
后续已新增 `carrier_incoming`，二者均可用时 `carrier_bridge` 为 true；
见独立的[入呼群振与网页首接仲裁](CARRIER_INCOMING.md)，能力标记不证明实网媒体可用。
活动通话显示实际规范化号码、模组 ID、阶段和双向包数，包数不证明听感。

验证包含真实回环 SIP／RTP、独立 Digest 客户端及两个合成 IMS 后端：外呼、
双向 PCM、取消／迟到返回、双方挂断、丢 ACK、逐线权限、并行模组、快速退出和
监听器重启防重。模拟媒体标为 AMR 仅测试 PCM 接口，不代表真实 AMR 网关验收。
界面以隔离 API 样例验证保存恢复、失败保留草稿、中文桌面及英文深色窄屏。

入呼多账号群振／网页首接仲裁已有独立合成验证，[手机短信桥](CARRIER_SMS.md)另有独立授权及队列。
剩余工作包括[可选 Asterisk 固定中继](ASTERISK_RELAY_PLAN.md)、真实多模式生命周期、
冷启动恢复与实卡验收。仅映射 SIP 端口不能提供公网语音；当前
服务仍只用于可信 LAN／VPN，并需放行实际 RTP 端口。
